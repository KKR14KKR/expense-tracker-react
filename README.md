# 💰 Personal Expense Tracker

A beginner-friendly expense tracking application built with React.  
This project was created to practice and strengthen fundamental React concepts through a practical application.

## 📌 About the Project

The Personal Expense Tracker allows users to add, view, and delete their expenses.

The application keeps track of the total amount spent and stores expenses in the browser using `localStorage`, so the data remains available even after refreshing the page.

## ✨ Features

- Add a new expense
- Enter expense description and amount
- Select an expense category
- View all added expenses
- Delete expenses
- Automatically calculate total spending
- Form validation
- Error messages for invalid input
- Save expenses using browser `localStorage`
- Restore expenses after refreshing the page
